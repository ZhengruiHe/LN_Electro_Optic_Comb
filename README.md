## 当前状态（2026-09-12）

当前本地版图主干为 **v7：M04 MUX + O型GSG150输入 + 有效长度修正的HTR终端**，是阶段工程候选，不是代工签核版。

- 15 mm T形电极保留，合并到21.8 × 3.8 mm有效block，原YSJ结构保留。
- 左侧150 µm GSG输入；右侧RF探针取消，采用片上单电阻终端。
- 方阻20 Ω/□为用户批准的估计值；裸露区31.25 × 12.5 µm，对应名义50 Ω；TiN含接触总长51.25 µm。

- 用户接受现有简化结果用于当前阶段，不等同于数值收敛、全片DRC或实测保证。
- 当前只聚焦黑盒损耗/串扰资料及工程交接；LN2映射、容差和额外场求解暂缓，不自动启动。
