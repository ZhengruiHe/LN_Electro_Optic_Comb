# v7 版图与复现版本说明

日期：2026-09-12

## 版本内容

本版本是当前 TFLN 四程电光梳工程的功能版图候选，主版图为：

results/layout/YSJ合并15mm_M04_KLink_v7_HTR有效电阻修正/YSJ与四程15mm_M04_O型输入_HTR有效50R_候选.gds

主要更新：

- 四个 MUX 统一采用 M04 750 µm 几何，耦合段 550 µm；
- MUX 输出接头重新按外部路由中心线对齐；
- 输入端改为参考 PDK o 型调制器的直线 GSG150 过渡；
- 右侧 RF GSG 探针取消，改用片上信号到公共地的 HTR 终端；
- HTR 终端按用户指定的 20 Ω/□估计值，实际裸露区 31.25 × 12.5 µm，名义 50 Ω；
- YSJ、15 mm T 形电极主体、光路和周期回路保留；
- 所有迭代版集中归档，恢复清单保留原路径和 SHA256。
