# 双端GSG探针连接说明

## 本轮结果与文件

2026-09-08更新：最新推荐工作稿为`results/layout/双端GSG150_窗口修正_v18_11/四程10GHz_15mm_GSG150um_分叉窗口修正_待验证工作稿.gds`；120 µm备选为`results/layout/双端GSG120_窗口修正_v18_02/四程10GHz_15mm_GSG120um_分叉窗口修正_待验证工作稿.gds`。这两版消除了原8个新增分叉窗口标记；下述v17继续保留为GSG金属和射频模型的输入基线。

在v16上加入两端外接GSG接口，主工作稿为150 µm相邻针尖中心距，另提供120 µm备选。用户已确认两种针距可后续调整；本轮没有冻结探针型号。

- 150 µm：`results/layout/双端GSG150_工作稿_v17_01/四程10GHz_15mm_双端GSG150um_待验证工作稿.gds`
- 120 µm：`results/layout/双端GSG120_工作稿_v17_01/四程10GHz_15mm_双端GSG120um_待验证工作稿.gds`

输入探针从左侧接入，输出探针从右侧接入。输出接口可用于接外部50 Ω负载，或接匹配测试仪器。GSG焊盘自身不是50 Ω终端，片上没有增加终端电阻。

## 参数

| 项目 | 数值或定义 |
|---|---|
| G-S、S-G针尖中心距 | 150 µm，备选120 µm |
| 有效落针区 | 每针50×50 µm，中心共线 |
| 信号焊盘金属宽度 | 50 µm |
| 焊盘纵向长度 | 120 µm |
| 过渡段长度 | 515 µm |
| 每侧新增接续总长 | 635 µm |
| 信号主干宽度 | 43 µm，沿用原有源电极 |
| 地电极内边缘 | y=±38.5 µm，过渡中保持平行 |
| 地电极外边缘 | 150 µm版焊盘处±190 µm，平滑接回±138.5 µm |
| 工艺层 | M1，42/0 |
| 落针标记 | 101/0非工艺注释；没有假定额外接触开窗层 |

50 µm信号焊盘宽度用于给当前光路留下间距；不能在当前位置直接扩展为任意大的正方形信号焊盘。地落针点位于加宽的地金属内，因此“150 µm针距”指三个接触中心的间距，不是宽地金属包围盒的中心距。

150 µm版本的输入落针点位于(1390,+150)、(1390,0)、(1390,−150) µm；输出位于(17610,+150)、(17610,0)、(17610,−150) µm。120 µm版只把相应纵坐标改为±120，并调整地电极外边缘。

## 实际GDS检查

两种针距均通过本轮检查：

- 三条导体保持相互独立且分别连续；两端信号接同一信号主干，上下地各接对应地主干，无短路或悬空。
- 六个50×50 µm落针区均完全落在所属金属上。
- 全M1线宽小于2 µm、间距小于3 µm的标记均为0；依据本地流片手册4.3节。
- 新增M1与LN1脊无平面重叠，最小间距约2.158 µm。此处2 µm避让下限是本次工程筛查值，不是额外推定的代工规则。
- 15 mm有源T形电极、原器件实例及全部光学图形保持不变。原有光学中心线长度和周期预算几何不变；新增金属对局部模式或射频加载的影响尚未求解。
- 删除了顶层原有两个RF占位框，并以实际M1接口取代；库黑盒内容与边界保持不变。

全片仍保留40个LN1核心线宽、42个LN1刻蚀区间距、6个SiN挖除间距标记，未新增光学规则标记。其中包含原有MUX标记与8个窗口分支标记；21层映射仍按用户要求暂缓。它们没有因新增GSG而解决，完整官方DRC也尚未完成。

检查文件在每版目录的`GSG连接与版图检查.json`，附源/输出哈希、落针坐标、连通性、前后规则计数与未完成项。绘图来自实际GDS回读多边形，另有KLayout原生截图。

## 使用与后续

```powershell
.\.venv\Scripts\python.exe -X utf8 models/layout/gsg_probe_connections.py --pitch-um 150 --output-dir results/layout/自己的GSG150新目录
.\.venv\Scripts\python.exe -X utf8 models/layout/gsg_probe_connections.py --pitch-um 120 --output-dir results/layout/自己的GSG120新目录
.\.venv\Scripts\python.exe -X utf8 models/layout/preview_gsg_connections.py results/layout/自己的GSG150新目录 --show
```

输出目录必须是新的，源v16不会被覆盖。脚本生成参数文件和GDS，随后用KLayout原生几何布尔运算验证。两端GSG接口的阻抗、S11/S21和过渡损耗还需要单独射频验证；探针头机械避让、接触尺寸与表面开口需要在实际型号明确后核对。本轮不运行制造容差，不改变MUX模型。

参考[FormFactor探针版图说明](https://www.formfactor.com/blog/2017/infinity-probes-layout-events-and-rules/)：针距以落针接触区定义，宽地金属不必是独立正方形；具体接触窗口要求应以所用探针型号为准。本版50×50 µm落针区是几何规划值，不代表对未知探针型号的兼容保证。

## v18：分叉窗口修正与GDS回读

修正仅针对20/1和10/2局部分叉窗口。适当扩大公共窗口，并以保留水平/竖直边的20nm误差限整理局部窗口边界，再处理1µm凹角；这些处理没有作用于20/0波导脊或42/0金属。修改区域的边界选在直段上，避免在弯曲边界硬拼接出细小台阶。

原2个新增LN1刻蚀区间距标记和6个SiN挖除间距标记均已消除。新版本实际GDS回读检查仍只有MUX本体的40个核心线宽和40个LN1刻蚀区间距标记；M1规则、核心覆盖和其他本轮检查为0项。21层最终映射仍未处理。

为兼容GDS记录长度解释，将单多边形顶点上限设为4000并保留层级。实际文件最大记录长度29524字节，小于32768。分割过程存在不超过1nm绘制格点的量化差异，M1回读完全一致；LN1核心异或面积0.000498µm²。回读后的规则计数与设计一致。不能把这种数值量化描述为逐字节不变，原工程均保留。

核心的设计宽度、中心线和300/350/300ps名义长度预算保持原方案。窗口变化的光学介质影响没有独立求解，本轮没有重新仿真MUX，也没有启动制造容差。

复现脚本为`models/layout/fix_euler_branch_windows.py`，以对应v17目录作为输入并使用新输出目录。中间失败尝试不作为推荐版；主版明确为`v18_11`，120µm备选为`v18_02`。

## GSG射频验证工程

已生成`results/hfss/gsg_launch/p150_model_v2/GSG150_Transition_10GHz.aedt`，HFSS2023 R1几何/边界/端口验证返回1。该工程尚未求解S参数。输入M1来自v17实际GDS，包含635µm接入段和有源T电极前500µm，两个平面波端口位于该局部模型两端，设置8–12GHz频段和10GHz自适应点。

介质沿用原射频材料假设：两条1.33µm LN脊、7.2µm有限残余平台和SiN位置全宽SiO2填充；尚未包括MUX局部变化、远处回路、真实探针针头及接触阻抗。因此该工程用于接口初步筛查，不能等同于完整实际探针模型或最终50Ω匹配结论。

```powershell
.\.venv\Scripts\python.exe -X utf8 models/rf/build_gsg_transition.py --layout-dir results/layout/双端GSG150_工作稿_v17_01 --output-dir results/hfss/gsg_launch/my_new_model
```

默认仅建模。`--solve`才请求求解，且脚本检测FDTD正在运行时不并行启动HFSS。AEDT2023 gRPC保存路径使用ASCII目录，中文说明与参数JSON仍保留。此前中文路径保存失败的尝试保留日志，不作为有效工程。
