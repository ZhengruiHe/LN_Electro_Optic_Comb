# 直LN1脊连接规划

> 本文的v9是直脊基线。其有源端`20/1/10/2`错位已在v10中改为平行公共窗口，见`docs/平行公共刻蚀窗口说明.md`；v9仍保留作几何来源。

## 定位

最新连接规划基线：`results/layout/_历史归档/迭代版本_20260912/直LN1脊连接规划_工作稿_v9_01/四程10GHz_15mm_直LN1脊连接规划_待验证工作稿.gds`。

用户要求先确认直波导，不在本轮优化圆弯和10 GHz延时。v8虽然让共同包络与有源轨道平行，却把1.95 µm位移转移给LN1主脊，使电极外连接出现S弯，不符合当前顺序，因此已否决。v9回到v6的直脊几何，并只作为端口与中心线审阅基线。

## 已确认的直连接

每个MUX有三段外接LN1脊：

- 有源主脊：局部`x=-200...0 µm`，中心恒为`y=-1.95 µm`，宽度1.33→1.40 µm；
- 外部主路：局部`x=750...950 µm`，中心恒为`y=-1.80 µm`，宽度1.10→0.70 µm；
- 外部辅助路：局部`x=750...950 µm`，中心恒为`y=1.45 µm`，宽度0.40→0.70 µm。

四个MUX共12个接口均与现有有源脊或外部0.7 µm路由连接，端点宽度和中心均通过实际GDS核查。v6修正后的0.30 µm辅助尾端保留。过程层几何和所有实例位置与v6完全相同；v9只更改顶层/单元状态名称和非工艺说明文字，方便区分审阅版本。

## 暂缓内容

- `20/1`与`10/2`仍采用v6的绘制包络，端面台阶和最终截面映射尚未解决。本轮审阅时将这些层隐藏，不能据此声称工艺掩膜已完成；
- MUX本体内部两条波导为实现模式耦合仍会靠近和分开，这不是外部连接弯曲；
- 全图现有圆弯和蛇形回路仅保留占位，未改欧拉弯，也未重新回填10 GHz群时延；
- RF焊盘、馈入和末端50 Ω连接尚未设计；
- 21层继续按用户要求暂不处理；完整光学级联、规则关闭和官方DRC均未完成。

## 复现

```powershell
.\.venv\Scripts\python.exe -X utf8 models/layout/prepare_straight_rib_plan.py `
  --output-dir results/layout/自己的直脊规划新目录
```

脚本读取v6后另存，检查12个接口和所有工艺几何未变化，并在KLayout新标签中只显示`20/0`，生成左右连接和整片LN1脊截图。
