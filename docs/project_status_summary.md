# LN 电光梳项目总览

更新时间：2026-08-30

## 1. 当前结论

本项目当前处于“架构确定、仿真流程与自动化框架完成、器件性能尚未验证”的阶段。

选定的主架构为：

```text
1550 nm CW
   -> 无周期极化的 LN 微环/跑道环 SHG（产生 775 nm）
   -> 分离的 1550 nm 与 775 nm 光路
   -> 共用一根 RF 行波电极的双光路相位调制器
   -> 两套间隔均为 fRF 的电光梳
```

其中只有 SHG 结构使用光学谐振腔，电光调制器采用非谐振行波结构。当前不采用 PDK 黑盒调制器，也不把周期极化 PPLN 作为首选方案；PDK 仅提供层叠、版图层、设计规则和芯片边界。

目前还不能声称已经得到低 `Vpi`、高 SHG 效率或完整双波长梳。已有数值均为文献参照、工程目标或仿真起始值，不是本项目的已验证结果。

## 2. 两个光频率和两套电光梳如何产生

LN 的二阶非线性 `chi(2)` 将基波角频率 `omega` 转换为二次谐波 `2omega`：

```text
1550 nm (omega) -> 775 nm (2omega)
```

微环的作用是同时增强 1550 nm 基波场和 775 nm 二次谐波场。它需要满足：

1. 在 1550 nm 附近存在一个泵浦谐振模式；
2. 在 775 nm 附近存在一个二次谐波谐振模式；
3. 两个模式满足足够好的相位匹配、空间模场重叠和双谐振失谐控制。

SHG 之后，同一个角频率为 `Omega = 2*pi*fRF` 的 RF 信号分别调制两条光路，产生：

```text
基波梳：omega + n*Omega
倍频梳：2omega + m*Omega
```

因此两套梳的梳齿间隔天然都为 `fRF`。这不意味着：

```text
fRF = FSR(omega) = FSR(2omega)
```

因为调制发生在微环外部的非谐振行波电极中。SHG 环的 FSR 只决定谐振模的纵向间隔；它不需要等于 25 GHz，也不要求 1550 nm 与 775 nm 的 FSR 相等。真正需要调节的是一个 1550 nm 模式和一个 775 nm 模式能否同时落在目标频率上。

## 3. 三个拟设计结构

| 编号 | 结构 | 目的 | 当前起始设计 | 预留面积 | 当前判断 |
|---|---|---|---|---:|---|
| S1 | 1550 nm 四次光学循环行波相位调制器 | 独立验证低 `Vpi` 与 25 GHz 电光梳 | 10 mm GSG；TE0/TE1 模式复用、交叉和回环使光场四次通过有源区；外部 50 ohm 终端 | 12.0 mm x 0.9 mm = 10.80 mm2 | 中高可行性，优先实施 |
| S2 | 无周期极化 SHG racetrack DOE | 独立验证 1550 nm 到 775 nm 转换 | 两个 SQPM/循环补偿几何解，加一个模式相位匹配备选；半径先扫 120–160 um；包含泵浦总线、775 nm 提取总线和加热器 | 三单元共 2.2 mm x 0.7 mm = 1.54 mm2 | 可测 SHG 为中等可行，高效率风险较高 |
| S3 | SHG + 双光路共电极集成结构 | 验证一片产生两套同间隔电光梳 | S2 后分出 1550/775 nm 光路；两条波导分别位于同一 GSG 电极的两个间隙内，先采用单次通过相位调制 | 12.5 mm x 1.0 mm = 12.50 mm2 | 风险最高，待 S1/S2 子结构收敛后实施 |

S1 的几何种子值为信号电极宽度约 43 um、信号—地间隙约 5.5 um，但必须通过 HFSS 扫参后重定。S1 的工程目标是 25 GHz 附近有效 `Vpi <= 2.5 V`，这是设计门槛而非已有结果。

S2 采用无周期极化的主要原因是避免精确极化反转工艺。其代价是有效非线性通常低于优化后的 PPLN/QPM，而且对环半径、直段长度、波导尺寸、晶向、色散及热漂移非常敏感。因此版图中保留多个几何 DOE，而不是只放一个理论最优环。

S3 中，两条光路处在 CPW 的两侧间隙，所见 RF 电场方向可能相反。这只会改变两套梳的相对调制相位或梳齿相位符号，不会改变梳齿间隔。

## 4. 芯片面积预算

PDK 可用芯片边界暂按 `21.8 mm x 3.8 mm = 82.84 mm2` 计算。

| 功能块 | 预留面积 |
|---|---:|
| S1 独立低 `Vpi` 调制器 | 10.80 mm2 |
| S2 三单元 SHG DOE | 1.54 mm2 |
| S3 集成双波长结构 | 12.50 mm2 |
| 合计 | 24.84 mm2 |
| 占有效芯片面积 | 约 30.0% |

三个结构沿芯片长度方向排布时，名义通道宽度合计约 2.6 mm，在 3.8 mm 芯片宽度内还剩约 1.2 mm，用于结构间隔、加热器走线、测试波导和局部控制结构。约 58.0 mm2 的剩余面积还要容纳光纤耦合区、RF pad、弯曲过渡、切割边界、TRL/校准结构、cutback、工艺监控和安全间距，因此 30% 不是最终版图利用率。

这些面积属于第一轮 floorplan 估算，误差建议按至少 `+/-20%` 看待，不能替代完整 GDS 排布。

## 5. 已知 PDK 起点与尚缺参数

当前采用的名义光学层叠起点为：

- x-cut TFLN；LN 厚度约 400 nm；
- SiN 厚度约 300 nm；
- LN 与 SiN 间氧化层约 400 nm；
- LN 最小线宽/间距约 0.30/0.30 um；
- LN 最小弯曲半径约 80 um；
- M1 最小线宽/间距约 2/3 um，RF 最小间隙不小于 3 um。

以下参数必须从 foundry/PDK 原始文件中确认，确认前不得进行最终模型签核：

- 衬底/handle 的材料和厚度；
- bottom oxide 厚度；
- LN1/LN2 的刻蚀深度、侧壁角和残余 slab；
- top cladding 厚度及损耗；
- M1 的材料、厚度、电导率和表面粗糙度；
- LN 的微波各向异性介电常数张量和损耗角正切；
- 有源区下方 SiN 是否保留；
- GSG 探针节距、pad 尺寸和允许的 taper；
- 背面是空气、金属 chuck 还是封装地；
- 775 nm 波导、耦合器和输出端是否在 foundry 支持范围内；
- 完整 DRC，而不只是已提取的最小线宽/间距。

## 6. 完整仿真流程

### WP0：锁定工艺截面和测试接口

从 PDK/代工厂确认上一节全部参数，同时确定 25 GHz GSG 探针、连接器或 wire-bond 的接口形式。输出唯一的 cross-section、材料表和测试 pad 约束。

完成门槛：`models/rf/hfss_cpw_config.json` 中 `foundry_inputs.confirmed` 可安全改为 `true`。

### WP1：1550 nm 与 775 nm 光学本征模

使用 Ansys Lumerical MODE 或 COMSOL Wave Optics，而不是 HFSS，完成：

- 两个波段的波导宽度、刻蚀深度和 slab 扫描；
- `neff`、`ng`、色散、损耗近似及模场分布；
- 1550/775 nm 单模或目标高阶模窗口；
- 金属间距对光吸收的约束；
- S1 的 TE0/TE1 模式复用、转换、交叉和弯曲损耗；
- S2 的基波/二次谐波模式族、相位失配和空间重叠。

输出：两个波段的光学场文件、`ng(f)`、候选波导截面以及 775 nm 最小安全弯曲半径。

### WP2：HFSS 行波电极

最终 RF 求解采用 HFSS 3D `Driven Terminal`。不把 Q3D 作为最终模型，因为 LN 的微波介电常数具有各向异性；Q3D 只能用于各向同性近似下的快速预筛。

模型层级为：

1. M0a：0.5 mm 均匀 CPW；
2. M0b：1.0 mm 均匀 CPW；
3. 用两长度 S 参数转 ABCD 后提取传播常数，降低端口寄生影响；
4. M1：筛选后的 10 mm 均匀电极；
5. M2：单独 pad/taper；
6. M3：pad + 10 mm line + pad 全结构；
7. M4：导出两条光路位置的 RF 复电场。

初始粗扫为 48 个截面：

```text
signal width Ws = 35, 43, 50, 60 um
gap G           = 4, 5.5, 7, 9 um
ground width Wg = 80, 100, 120 um
```

求解 1–50 GHz，在 5、25、50 GHz 自适应；`maxDeltaS = 0.01`，最多 12 个 passes，至少连续 2 次收敛。端口为两端 Driven Terminal wave port，信号为 terminal、两侧地为 reference conductor；同时保存原生特性阻抗和 50 ohm renormalized S 参数。

HFSS 需要分别评估开放背面和金属 chuck/封装背面。最终损耗模型必须使用真实金属电导率、厚度和粗糙度，不能把金属设为 PEC。

筛选门槛暂定：

- 20–30 GHz 内 `45 ohm <= Re(Z0) <= 55 ohm`；
- 完整 pad 模型在 20–30 GHz 内 `S11 < -10 dB`；
- 25 GHz RF 衰减优选不高于 4 dB/cm；
- S1 优选 `|nRF - ng_1550| <= 0.1`；
- S3 在两条光路上的速度失配惩罚均不高于 1 dB；
- 网格、airbox、端口面和金属厚度收敛，无局部电流异常热点。

### WP3：电光重叠和 `Vpi` 提取

HFSS 只提供每单位端口电压对应的 RF 场，不能单独计算 LN 光学模或 `Vpi`。将 HFSS RF 场和 WP1 的光学场插值到同一截面，按 LN 晶轴旋转电光张量，分别计算：

- 1550 nm 单次通过 `Vpi*L`；
- S1 四次通过后的有效 `Vpi`；
- S3 两条光路各自的 `Vpi*L` 和相对调制相位；
- RF 损耗、光学群速度失配和端口反射共同作用后的频率响应。

如果 S1 在合理 RF 功率下仍达不到目标，应先调整电极间隙、光学模式循环次数或有源长度，再决定是否扩大面积。

### WP4：无极化反转 SHG 微环

用 MODE/COMSOL 得到的 `neff`、色散和模场，扫描环半径、直段长度、波导宽度和模式组合，寻找：

- SQPM/循环相位补偿条件；
- 1550/775 nm 双谐振模式对；
- 足够大的非线性重叠积分；
- 可制造的 bus gap 和两个波段的外耦合 Q；
- 热调谐范围可覆盖 fabrication detuning；
- 对尺寸、温度和折射率误差不至于过度敏感。

建议先用本征模和耦合模理论进行大范围参数扫描，再对少量候选结构使用 3D FDTD/EME 或 COMSOL 验证耦合器、弯曲和散射。HFSS 不负责此步骤。

### WP5：热调谐与双谐振控制

在 COMSOL Heat Transfer 或 Ansys 热模块中计算加热器的稳态温升、热串扰和响应时间，再把温度场映射回两个波段的谐振频移。需要确认单个或多个 heater 是否能同时补偿 1550/775 nm 的不同热光响应。

这一阶段必须给出锁定方案：至少需要监测泵浦透射，形成 side-of-fringe、dither 或 PDH 类误差信号，并考虑热双稳态、锁定范围、控制带宽和失锁恢复。仅靠静态扫温不能替代实际双谐振控制。

### WP6：双波长电光梳系统级模型

将 SHG 输出功率、两个相位调制指数、RF 损耗、光学损耗、残余反射和探测带宽加入 Python 系统模型，预测：

- 两套梳的线数和 3 dB/10 dB 带宽；
- 单梳齿功率和功率不平坦度；
- RF 功率需求；
- 1550/775 nm 梳的相对相位；
- RF 源相位噪声到各梳齿的传递。

这里先验证“能否同时产生两套可测梳”，暂不把高倍频或频率分频性能作为本阶段验收指标。

### WP7：版图与流片前验证

只有 WP1–WP6 的关键参数收敛后才生成最终 GDS。版图中需要同时放置：

- S1、S2、S3 主结构；
- 均匀 CPW、pad、open/short/load/thru 或 TRL 校准结构；
- 光学 straight/cutback、bend、crossing、mode mux 和耦合器测试单元；
- SHG 环半径、直段、bus gap、heater 的 DOE；
- 金属到两个波段波导的吸收间距 DOE；
- 对准标记、切割区和电热测试 pad。

最后完成 PDK DRC、版图与仿真截面一致性检查，以及 RF/光纤/热控联合可探测性检查。

## 8. 风险排序与决策门槛

| 风险 | 级别 | 主要原因 | 降低风险的方法 |
|---|---|---|---|
| S1 低 `Vpi` 与宽带匹配 | 中 | 400 nm LN 栈与文献器件不同；四次循环引入额外损耗和相位误差 | 先做 MODE + 两长度 HFSS + EO overlap，再做完整 pad |
| S2 可测 SHG | 中 | 无周期极化的有效非线性较低，双谐振和几何误差敏感 | 三单元以上 DOE、heater、独立 775 nm 提取端 |
| S2 高效率 SHG | 高 | 相位匹配、Q、耦合和热失谐需同时满足 | 把“可测 SHG”和“高效率”设为两个验收阶段 |
| S3 双波长共电极 | 高 | 两个波段的吸收、EO 重叠和群速度无法同时天然最优 | 双光路独立截面，共用 RF；先做单次通过方案 |
| 775 nm 工艺支持 | 高/待确认 | PDK 可能未对可见光损耗、耦合器和 DRC 签核 | 尽早向 foundry 提交截面和器件询问 |
| 双谐振长期稳定 | 高 | 温度漂移和泵浦热效应会使两个谐振不同步 | heater + 误差信号 + 闭环控制设计 |

建议的阶段性 go/no-go 顺序为：

1. 工艺层叠与 775 nm 支持确认；
2. S1 截面满足 50 ohm、RF 损耗、速度匹配和 `Vpi` 目标；
3. 至少一个 S2 候选在容差分析中保留可测 SHG；
4. S3 两条光路均具有可接受的吸收、EO overlap 和 RF 响应；
5. 最后才做整片 GDS 和 tapeout 评审。

## 9. 当前不应直接做的事情

- 不把文献的 `Vpi`、SHG 效率或 Q 值写成本项目结果；
- 不直接照抄 500/600 nm LN 文献结构到当前 400 nm LN 栈；
- 不用 HFSS 代替光学本征模和非线性仿真；
- 不一开始仿真整片 10–20 mm 的全部 pad、回环和微环；
- 不强行令 `fRF = FSR_1550 = FSR_775`；
- 不在缺少 foundry 材料和金属参数时签核 RF 损耗；
- 不在 S1/S2 子结构未验证前冻结 S3 最终版图。

## 11. 下一步的最短执行路径

当前最有效的下一步不是继续增加版图细节，而是完成以下三件事：

1. 从 PDK/foundry 锁定 RF 金属、衬底、氧化层、LN 刻蚀和 775 nm 支持参数；
2. 在装有 HFSS 的电脑上运行 0.5/1.0 mm 均匀 CPW 粗扫，得到真实 `Z0`、`nRF` 和 RF loss；
3. 同时在 MODE 中完成 1550/775 nm 光学模式扫描，为 `Vpi*L`、SHG 相位匹配和双谐振设计提供输入。

完成这三项后，才能用数据决定 S1 的最终电极截面、S2 的环半径/直段以及 S3 是否能在同一 RF 电极下兼顾两个波段。
