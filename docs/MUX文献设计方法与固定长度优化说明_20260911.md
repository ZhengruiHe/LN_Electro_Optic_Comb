# MUX文献设计方法与固定长度优化说明

更新：2026-09-11。本文用于学习模式复用器设计方法，不把文献尺寸直接当作当前南智 PDK 参数。

## 1. Zhang 等人的四程电光梳 MUX

论文：Ke Zhang 等，*A power-efficient integrated lithium niobate electro-optic comb generator*，Communications Physics 6, 17 (2023)，[论文原文](https://doi.org/10.1038/s42005-023-01137-9)。

该工作的 MUX 不是先固定某个波导间隙再盲目加长，而是按照以下逻辑设计：

1. 主支路逐渐变窄，使主支路 TE1 的有效折射率下降；
2. 辅助支路逐渐变宽，使辅助支路 TE0 的有效折射率上升；
3. 两个同偏振模式的有效折射率轨迹发生交叉；
4. 通过有限间隙形成明显的超模避免交叉；
5. 让结构足够绝热，使 TE1 能量沿超模连续演化到辅助支路 TE0，而主支路 TE0保持直通。

论文给出的耦合区长度为550 µm，耦合间隙约500 nm，避免交叉的超模折射率分裂约0.01。作者通过不同位置的本征场图和有效折射率演化图确认模式路径，再用级联 MUX 测量损耗和串扰；其测试结构报告1530–1630 nm范围内光学损耗低于0.4 dB、串扰抑制优于20 dB。[论文第2–4页](https://www.ee.cityu.edu.hk/~cwang/document/A%20power-efficient%20integrated%20lithium%20niobate%20electro-optic%20comb%20generator.pdf)

作者还明确指出，未完全转换的模式会在多程回路中产生干涉条纹，进一步优化的直接旋钮包括耦合长度和耦合间隙。这支持“轨迹和相位匹配比单纯加宽一个端点更关键”的判断。

## 2. Quan 等人的三波导绝热设计

论文：Qihong Quan 等，*Broadband adiabatic mode division (de)multiplexer in thin film lithium niobate*，JOSA B 40, D72–D77 (2023)，DOI [10.1364/JOSAB.484402](https://doi.org/10.1364/JOSAB.484402)。

该方法使用三个波导和受控的绝热转移，中心波导采用倾斜/渐变结构，使目标模式转移时中心波导只被弱激发。论文同时优化耦合系数、各段长度和间距，TE1转换效率约94.6%，并不是只改变一个波导宽度。[Optica论文页面](https://opg.optica.org/josab/abstract.cfm?uri=josab-40-5-D72)

这是一种可备选的结构机制，但当前项目的四程 MUX 已采用双波导方案，且版图约束、晶轴和黑盒接口不同，不能直接替换。

## 3. 其他双芯绝热锥形设计给出的启示

LNOI 双芯绝热耦合器常把主总线逐渐变窄、访问波导逐渐变宽，并把耦合段分成“解耦—主要转换—再解耦”三段。已有文献中会分别扫描两端宽度、中心耦合间隙和三段长度；例如有工作使用约0.25 µm的局部间隙，但这不满足当前项目要求的最小芯层间距大于0.60 µm，因此只能作为方法参考，不能照搬尺寸。

## 4. 对当前 PDK 的正确迁移方式

当前约束：

- LN总厚度400 nm，LN1刻蚀200 nm，侧壁与水平面70°；
- MUX总长度750 µm，中央耦合段550 µm固定；
- 辅助脊起始宽度至少0.35 µm，以避开0.30 µm临界线宽；
- 两条芯层最小边缘间距严格大于0.60 µm，本轮候选下限取0.65 µm；
- 1550 nm工作点，主TE0直通、主TE1转辅助TE0。

在固定长度下，应把设计变量写成连续轨迹，而不是孤立端点：

\[
w_m(x),\quad w_a(x),\quad g(x),\quad 0\le x\le550\,\mu m.
\]

其中主宽度、辅助宽度和边缘间隙共同决定局部 \(\Delta\beta(x)\) 与超模分裂。设计目标不是让某一点折射率相等，而是让目标模式在避免交叉区域缓慢、连续地交换支路归属。

## 5. 固定750 µm时的推荐优化顺序

### 第一步：端点本征模

在输入和输出端分别确认主TE0、主TE1和辅助TE0的物理身份，不能只看求解器编号。辅助脊加宽后端口模式编号可能重排，这是前一轮筛选需要修正的原因。

### 第二步：局部 FDE 轨迹图

沿耦合段取31个或更多位置，记录：

- 主TE1与辅助TE0的局部有效折射率；
- 两个相关超模的最小折射率分裂；
- 目标模式的主/辅芯区能量比例；
- 模式变化最快的位置及其宽度斜率。

优先调整渐变指数和比例，使避免交叉附近的宽度变化变慢，同时保证整个耦合段不超过750 µm。

### 第三步：固定长度 EME

总长度固定750 µm，采用100/550/100 µm三段。对每个轨迹候选读取完整复S矩阵，并按已核对的端口场形投影到物理模式：

- TE0直通效率；
- 主TE1→辅助TE0效率；
- 辅助TE0→主TE1效率；
- 反射和非目标模式功率。

名义筛选建议同时满足目标通道大于95%、串扰低于−20 dB；若达不到，不直接放入版图。

### 第四步：只对优选轨迹做精细检查

对最优候选提高 EME 中央单元数、网格和端口模式数，重新核对波长、端口模式身份和复S相位。粗筛结果只能用于排序，不能称为收敛签核。

## 6. 当前结果的正确解读

此前辅助脊0.35→0.40 µm、间隙1 µm的单点修改把主TE1→辅助TE0降低到约7.4%，说明原轨迹与新端点宽度不再匹配。随后六个联合候选在端口编号校正后最高约49.9%，说明“间隙、末端宽度和长度同时做少量离散修改”仍不够；大于750 µm的深渐变候选已因时延约束取消。

因此当前最值得学习和优化的是**固定750 µm内的轨迹形状**，而不是继续增加耦合长度。最小间隙只需满足大于0.60 µm，具体优先考察0.65 µm附近；末端宽度作为改变局部相位匹配的旋钮，与渐变比例一起优化。
