# 平行公共刻蚀窗口

> v10已解决四个有源端的平行窗口接续；其MUX外端分支窗口已在v11中局部加宽，见`docs/MUX外端公共窗口加宽说明.md`。v10继续保留为输入基线。

## 最新工作稿

`results/layout/直脊平行公共窗口_工作稿_v10/四程10GHz_15mm_直脊平行公共窗口_待验证工作稿.gds`

本版以v9直LN1脊为基础，只重新定义四个MUX与有源段连接处的`20/1`和`10/2`平面窗口；LN1脊、电极、圆弯、长回路、交叉黑盒和实例位置均不改变。

## 几何选择

MUX全部LN1脊的局部横向范围为`-2.65...1.80 µm`。有源主脊中心为`-1.95 µm`。若共同`20/1`窗口保持与主脊同中心，并要求最外侧辅助脊至少留0.30 µm名义横向余量，则上边界需要达到`1.80+0.30=2.10 µm`，相对主脊中心的半宽为4.05 µm。因此选择：

- `20/1`宽度8.10 µm，中心`y=-1.95 µm`，边界`-6.00...2.10 µm`；
- `10/2`宽度保持17.20 µm，中心同样为`y=-1.95 µm`，边界`-10.55...6.65 µm`。

有源双轨的`20/1`同步从7.20 µm改为8.10 µm，中心仍为全局`y=±30 µm`；`10/2`保持17.20 µm。因此每个MUX有源端的两层窗口与对应有源轨道等宽、同中心、平行直连，不再有错位台阶、斜包络或LN1 S弯。

## 核查结果

- 四处`20/1`与`10/2`均完整宽度连接；
- MUX全部LN1脊均位于两个窗口内；
- 所有`20/0`、M1、实例位置及其他子单元未改变；
- LN核心间距、刻蚀窗口线宽、SiN窗口线宽/间距及M1线宽/间距没有新增标记；
- 仍有40条LN核心线宽及40条LN1刻蚀区间距标记，来自MUX本体0.30 µm辅助脊的法向宽度/1 nm格点问题，不是公共窗口新增。

## 边界

这是名义版图规划，不是已验证工艺截面。`20/1`从7.2变为8.1 µm会改变第一次刻蚀范围，可能影响有限平台边界、光学模式、微波介电加载和速度匹配。原MUX EME和HFSS结果不能自动视为v10的验证结果，后续需要按最终截面重新核对。外部主/辅助双支路分离端的窗口接续、21层、圆弯、10 GHz时延、RF焊盘与终端仍按当前顺序暂缓。

## 复现

```powershell
.\.venv\Scripts\python.exe -X utf8 models/layout/align_parallel_mask_windows.py `
  --output-dir results/layout/自己的平行窗口新目录
```
