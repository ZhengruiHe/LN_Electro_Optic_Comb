## 几何处理

- 最小曲率半径为80 µm，欧拉比例为0.4。
- 第一、第三回路采用六个欧拉U弯，其中末端分三级落回，避免原单个大半径弯侵入输入光路。
- 第二回路采用三个180度和两个90度欧拉弯。
- 输入采用两个90度欧拉弯接入左上模式复用器。
- 水平和竖直之外的短折线只用于离散连续欧拉曲线；超过2 µm的直线段全部与坐标轴平行，不存在斜直波导。
- 输入与回路2只在(300,250) µm通过已放置的正交交叉器相交，其余中心线无自交或非预期相交。
- 20/1和10/2在四组近邻端口处分支时采用局部公共矩形窗口；这不改变20/0光学核心的几何中心线长度。窗口变化对实际群折射率的影响未独立求解，本轮直接计算仍沿用已有材料及模式数据。

## 版图检查结果

生成后回读确认11个层次化实例保持不变，包括四个模式复用器、有源区、T形电极、交叉器、端口拉锥和端面耦合器。20/0顶层包含7个无源路由片段；20/1和10/2各包含7个路由片段及4个局部公共窗口。

手册名义规则差分结果：v11共有85个标记；当前版共有93个标记。40个LN核心线宽、40个LN1刻蚀区间距和5个“两次刻蚀映射缺失”沿用v11已知状态；欧拉版新增2个LN1刻蚀区分支点间距和6个SiN挖除分支点间距标记。它们位于四组公共窗口终止位置，性质与模式复用器内已有的渐分支标记相同，但尚未获得代工方豁免，因此不能写成正式DRC通过。

## 2026-09-08：全光路时延直接核算

按用户指定范围，MUX沿用已有仿真及群时延，不重新仿真；欧拉弯先采用现有Y/Z群折射率和方向插值直接积分。本轮保留v16波导几何，补齐输入端、第四程及输出端的时延账目。

参考面取输入端面耦合器的片内端口(0,250) µm到输出端面耦合器的片内端口(18700,-26.6) µm。两只耦合器黑盒本体不包括在这个参考面范围内。

| 光程段 | 名义时延(ps) |
|---|---:|
| 输入片内端口→第1程有源入口 | 15.742 |
| 第1程入口→第2程入口 | 300.000 |
| 第2程入口→第3程入口 | 350.000 |
| 第3程入口→第4程入口 | 300.000 |
| 第4程有源入口→输出片内端口 | 123.387 |
| 两片内端口间总计 | 1089.128 |

所有光程包含4次15mm有源区传播、8次750µm MUX本体通过、8段有源接续拉锥、8段MUX外端接续拉锥、6段0.7/1.2µm接口拉锥，以及交叉黑盒横向和纵向各通过1次。直段与欧拉弯按保存的中心线分类积分，黑盒和接口拉锥从整条路由中拆分列出，未重复叠加。

各回路两端有源拉锥分别按前一程和后一程的TE模式取既有平均群折射率；原预算将两端按前一程统一处理，故本次三程间隔分别出现约−0.000231/+0.000231/−0.000231 ps的账目修正，对应10 GHz下约±0.000831°。该差异远小于现有材料、晶向插值和黑盒估算的不确定度，本次未为消除这项算术差异修改版图。

1.089 ns是当前模型下的端口间传播时间，包含工程估算。交叉器与六段接口拉锥仍使用0.7µm同晶向群折射率占位；端面到端面的总时延还需两只耦合器黑盒本体的数据。MUX和有源区域继续沿用已有结果，不以本次积分宣称新光学求解完成。
