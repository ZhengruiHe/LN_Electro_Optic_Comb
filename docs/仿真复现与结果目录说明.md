# 仿真复现与结果目录说明

## 一、Git保存什么

本仓库用于复现和学习，因此Git只保存：

- `models/`中的MODE、HFSS、Maxwell 2D、版图和系统级建模脚本；
- PDK允许公开的非敏感参数配置；
- `scripts/`中的数据提取与核查脚本；
- 中文原理、运行方法、输入输出定义和当前结论。

本地PDK原文件、代工保密资料、软件工程文件和仿真结果不上传Git。

## 二、本地结果如何保存

`results/`保存所有本机计算结果，并被`.gitignore`整体忽略。扫描结果需要保留，不能删除，只是与名义基准分开归档：

```text
results/
├─ optical/
│  ├─ 名义工程、选定参数和阶段报告
│  └─ 扫描结果/
│     ├─ 波导截面/
│     └─ 模式复用器/
├─ hfss/
│  ├─ 当前T形电极和普通CPW基准
│  └─ 扫描结果/
├─ eo/
│  ├─ 当前T形电极基准
│  ├─ regular_cpw/
│  └─ 扫描结果/
├─ layout/
└─ system/
   ├─ 当前基准报告
   └─ 扫描结果/
```

每次扫描应新建能说明变量和版本的子目录，例如`扫描结果/电极对照/15mm/`。不得用同一文件名覆盖已验证的名义结果。

## 三、推荐复现顺序

1. 用`models/optical/mode_pdk_sweep.py`验证有源波导TE₀、TE₁及群折射率；
2. 用`models/optical/mode_mux_cross_section_sweep.py`寻找TE₁与辅助TE₀的避免交叉；
3. 用`models/optical/mode_mux_eme.py`验证有限长度模式复用器的S矩阵和传播场；
4. 用`models/rf/build_hfss_cpw.py`建立两种长度的行波电极，再提取`nRF`、阻抗和损耗；
5. 用`models/eo/`中的脚本计算Maxwell 2D单位电压场和Pockels重叠；
6. 用`models/system/simulate_four_pass_comb.py`合成四程相位、半波电压和理想梳谱；
7. 用`models/layout/generate_four_pass_layout.py`核查2T、2.5T、2T时延和版图占位。

先完成名义结构的功能闭环，再进行线宽、刻蚀、侧壁角、膜厚和间隙容差。容差扫描不能代替名义功能验证。

## 四、当前本机环境

- Ansys Electronics Desktop/HFSS 2023 R1；
- Maxwell 2D 2023 R1；
- Ansys Lumerical MODE 2023 R2；
- 项目Python虚拟环境：`.venv`；
- PyAEDT已安装在项目虚拟环境中。

先运行以下命令检查脚本和软件接口：

```powershell
.\.venv\Scripts\python.exe -m py_compile `
  models\optical\mode_pdk_sweep.py `
  models\optical\mode_mux_eme.py `
  models\rf\build_hfss_cpw.py `
  models\eo\calculate_eo_overlap.py `
  models\system\simulate_four_pass_comb.py

.\.venv\Scripts\python.exe models\rf\build_hfss_cpw.py check
.\.venv\Scripts\python.exe models\rf\postprocess_tline.py --self-test
```

具体命令和结果解释分别见：

- `models/optical/README.md`；
- `docs/模式复用器EME仿真思路与建立方法.md`；
- `models/rf/README.md`；

## 五、结果可信度标记

复现时必须区分：

- 已由求解器得到的数值结果；
- 由不同求解器结果合成的工程预测；
- 来自论文或Ansys示例的材料起始值；
- 尚待代工方确认的工艺参数。

当前梳齿数采用理想纯相位贝塞尔谱，尚未完整加入模式复用器、回环、弯曲、交叉和各程幅度不均衡，因此不能作为实验保证值。半波电压使用的`r33`和`r13`也不是代工实测系数。
