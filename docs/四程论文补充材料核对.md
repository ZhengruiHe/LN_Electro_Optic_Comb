# 四程论文补充材料核对

## 文件身份

本地文件`42005_2023_1137_MOESM2_ESM.pdf`是Zhang等人《A power-efficient integrated lithium niobate electro-optic comb generator》的9页补充材料，包含回路延迟线、交叉损耗、模式复用器和转换效率的补充说明。

## 回路延迟的确定事实

1. 论文以25 GHz为目标射频。四程增强只有在各程调制相位正确时才能达到理想的4倍。
2. 论文的回路总长度包含调制波导、模式复用器、锥形过渡、Euler弯曲和外部回环波导。
3. 各分段因宽度、模式和LN晶向不同而具有不同群折射率；论文逐段计算群时延，而不是用单一平均值直接乘总长。
4. 论文三段回路总长为26.666、28.987和20.886 mm，相对25 GHz周期的延迟分别为5.0003T、5.5000T和3.9999T。
5. 第二回路必须为半整数周期，以补偿GSG上下调制区电场极性的pi相差。
6. 回路原则上应尽可能短以降低光损耗，但还必须足以容纳实际回环。论文第二回路没有选4.5T，因为该长度不足以完成物理回环。

## 模式复用器的确定事实

- 论文候选的耦合间隙为500 nm；
- 两条耦合波导总宽为2.7 µm；
- 侧壁与水平面夹角为67°；
- 上包层采用SiO2；
- 避免交叉中的模分裂约为0.01；
- 耦合段长度为550 µm，理论估计在长度超过400 µm时转换率已接近100%。

## 对当前10 GHz设计的影响

- 历史10 mm调制臂使用2T/2.5T/2T候选周期数。当前15 mm电极版本采用3T/3.5T/3T；两版不应混用，详见《四程名义GDS生成与检查说明》。
- 回路长度将改为逐段群时延积分，平均`ng`只用于初始版图骨架。
- 当前PDK的70°模式复用器在1.0 µm间隙下得到约0.0189的模分裂，550 µm耦合段的精细EME名义转换率约99.7%。这与补充材料的绝热性判据相符，但仍需工艺容差验证。
- 原25 GHz工程和结果保留为参考，不覆盖。

## 2026-09-05：波导交叉器原文核对

Zhang等2023年[主文](https://www.nature.com/articles/s42005-023-01137-9)的Overall design段明确说明四次调制后的光经低损耗波导交叉器向右输出；图1f是交叉器SEM。这里是实体波导的平面交叉，不是模式复用器本征值中的“避免交叉”。

本地补充材料第4页Supplementary Note 2和Fig. S2给出的事实是：

- 使用0、10、20个交叉器级联的直波导进行损耗拟合；
- 因LN各向异性，分别沿晶体Y方向和Z方向设计、优化和测试；
- 平均单次损耗分别为0.18 dB和0.10 dB；作者给出完整器件中交叉贡献合计0.28 dB；
- 这些是论文器件的实测结果，不是本项目PDK的指标。不能假定两个晶向等效，更不能把0.28 dB直接写成当前结构仿真结果。

因此，四程版图允许存在经过设计的交叉器；应纠正的是未定义、未验证的斜交，而不是一概禁止所有交叉。当前候选拟采用本地PDK的45×45 µm LN交叉黑盒端口约定，但真实掩膜、光学复S参数和0.7 µm路由到PDK默认1.2 µm端口的过渡尚未验证。保持10 GHz时延还需要对新增器件和转向逐段回标。
