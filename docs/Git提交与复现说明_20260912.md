## 结果中的已知更正与限制

### HTR终端

v5h/v6c初版将TiN总长度误当有效长度，实际裸露区15 µm，按20 Ω/□约24 Ω。v7通过实际GDS的HTR减M1覆盖区计算，确认有效区31.25 × 12.5 µm。旧版仍保留用于追溯，不再推荐使用其终端。

### HFSS输入模式

Touchstone中端口1/3为Odd，端口2/4为CPW。按脚本的物理CPW约定，10 GHz结果为S11约−36.192 dB、S21约−0.130 dB。此前−25.78/−0.085 dB是Odd模式，不能继续作为物理GSG输入结论。

模型只包含321 µm输入和500 µm均匀主干；不含15 mm周期T帽和HTR终端，材料沿用工程参数。求解结束不等于所有收敛门槛均满足。

### 光学吸收

保留的TiN/Al数据为1 µm覆盖金属的简化单波导截面。原脚本在LN刻蚀区的SiO2填充有遗漏，没有按真实GDS四条芯线逐一建模，也未计算有限桥边缘散射。TiN厚膜测试不等于实际HTR薄膜。记录的Al约9.96e-5 dB和TiN约0.00110 dB是该模型TE0的20 µm长度外推，不作为实际整片损耗保证。

这次只记录证据边界，不修改原始结果、不重跑仿真。
