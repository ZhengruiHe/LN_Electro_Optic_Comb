# 黑盒交叉器拉锥工作稿

## 当前文件

新工作稿：`results/layout/_历史归档/迭代版本_20260912/黑盒交叉_拉锥工作稿_v5/四程10GHz_15mm_PDK黑盒交叉_拉锥接续_待验证工作稿.gds`。

该版本基于v4生成，保留15 mm电极、四处MUX、三段回路、原始端面耦合器及其层级。既有GDS、PDK黑盒源文件、仿真结果都未覆盖。当前只有这一份完整工作GDS，不提供可能被误作提交件的展平工艺层副本。

## 接续变化

1. 将(300,250) µm处的自定义交叉替换为原生`crossing_ln`，45×45 µm，保持原名和原内容，仅平移、不旋转、不镜像。
2. 四个黑盒端面各接100 µm长的LN1拉锥。外端0.7 µm，黑盒端1.2 µm；宽度按三次平滑函数变化，两端斜率为零。它是绘制几何，不是已验证的绝热长度。
3. 输入、输出的端面耦合器片内端口也为1.2 µm，所以另补两段相同拉锥，避免0.7与1.2 µm直接阶跃连接。合计新增6段。
4. 拉锥外接段的20/1绘制包络保持7.2 µm，10/2的SiN挖除窗口保持17.2 µm。这不是声称残余LN2实际宽度已确定；没有擅自增加21层刻透区域。
5. 当前端口几何位置为西(277.5,250)、东(322.5,250)、北(300,272.5)、南(300,227.5) µm。西东接输入光路，北南接回路2。100 µm锥形位于原直线段内，没有侵入东侧弯曲。

拉锥宽度定义：`w(u)=0.7+0.5*(3*u^2-2*u^3)` µm，`u=s/L`。脚本保留长度参数，但现有固定位置限制`L<=120 µm`；改变布局后应重新核对可用直段。

## 已检查

- 1 nm绘制格点，保留黑盒及器件层级，只一个顶层。
- 原有子单元和实例保持不变；原始黑盒复制后的内容签名一致。
- 六处拉锥宽端均为1.2 µm，窄端均为0.7 µm，并与原路由连续。
- 用户自画20/0、20/1、10/2未侵入交叉器及两只端面耦合器的真实黑盒边界。
- 六处局部窗口外的几何保持不变，原中心线拓扑不新增交叉。
- 新增区域0.3 µm LN芯层及刻蚀区线宽/间距检查为0项。

上述检查不能代替全片官方DRC。整片仍有48条原LN核心线宽标记、44条原LN1刻蚀区间距标记，主要涉及继承的MUX窄尾端，不应理解为92个独立器件缺陷。

## 仍未验证

### 电极平面规则核查补充（2026-09-07）

从v5实际GDS读回的`M1 (42/0)`是15 mm周期T形GSG：信号主干宽43 µm，两侧地主干各100 µm；300个50 µm周期，帽部长45 µm、横向宽2 µm，颈部沿传播方向宽10 µm、横向伸长4 µm。帽部占空比90%，相邻帽部端隙5 µm，对向信号/地帽部调制间隙5 µm，帽部与所属主干之间的局部空隙4 µm。

脚本`models/layout/audit_electrode_pdk.py`只读核查整个M1合并区域。小于2 µm的线宽、小于3 µm的间距均为0项；合并后为三条各15 mm连续导体，没有T分支悬空或信号与地短接，M1与LN1脊的平面重叠为0。核查前后GDS哈希不变。两条地主干尚未画入正式接地焊盘和终端网络，三条独立导体不等于已完成外部接地。

结果：`results/layout/_历史归档/迭代版本_20260912/黑盒交叉_拉锥工作稿_v5/电极PDK核查_01/T形电极_PDK几何核查.json`，同目录有实际KLayout局部截图。此结论仅为当前已公开M1规则的名义平面几何检查通过，不代表厚度、材料、光学金属吸收、射频性能或官方流片签核通过。2 µm帽部恰好位于手册下限，尚未评估制造裕量；当前不执行工艺容差扫描，也不为增加裕量擅自改变射频候选尺寸。

### 接续与全片待验证项

- 0.7 µm自定义路由与PDK默认1.2 µm单模端口的完整截面一致性；7.2 µm包络不能自动当作有限LN2平台。
- 新拉锥在两个晶向的目标模式传输、辐射和相位；当前未启动新仿真。
- 黑盒内部复S矩阵及群时延。手册`crossing_ln <0.2 dB`为参考值，并未在表中按晶向分列，不能替代本机结果或流片保证。
- MUX本体外侧的旧拉锥/包络接头、0.15 µm尾端及LN2掩膜问题没有在本轮掩盖或强行修正。
- 保持中心线几何长度不等于保持10 GHz群时延；需要回填拉锥和黑盒的实际时延。
- 焊盘、终端、全链路与官方DRC仍未完成。本文件明确是工作稿，不可作为最终流片交付。
