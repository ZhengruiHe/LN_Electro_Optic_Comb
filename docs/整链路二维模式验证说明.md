# 整链路二维模式验证说明

2026-09-11阶段更新：基础组件15项、近邻8例均已生成结果；用户接受现有二维工程结果并停止追加计算。两例时间窗初筛不改写为能量停止，完整相干级联未完成。最新采用范围以[阶段交付核查与进展](阶段交付核查与进展_20260911.md)为准。以下保留当时的方法和过程记录。

更新：2026-09-09。本轮按用户要求检查整个四程光学链路的模式影响，9只PDK交叉器已获用户同意按理想直通占位。当前已完成方法校准及部分组件，基础组件和近邻联合仿真正在分批执行；**完整链路级联尚未完成**。

## 范围与方法

输入、输出、三条回程使用当前v13_03对应的实际路线，15 mm电极、MUX耦合核心、GSG及YSJ源GDS不改。不做工艺容差，不重跑射频、电光梳谱或MUX核心优化。

采取“分段2D场求解 + 既有矢量MUX/有源段模型 + 多模式复幅度级联”。直段保留实际长度及传播相位；重点求解弯曲、拉锥以及四组近邻接入。近邻区域必须把两条波导同时放入同一求解域，不能用孤立弯曲结果代替。

1550 nm为唯一保存的光学频点。短脉冲光源需要一定带宽，不等于扫描很宽的工作波长。源模、端口及场监视器分别读取实际波长，不只信任文件名。

直接覆盖整个毫米级block的均匀2D细网格仍然很大。例如21.8×3.8 mm、100 nm网格约82.84亿个平面网格点，还没计算时间步；因此本轮不直接开启整片单域FDTD。

## 为什么没有直接采用默认varFDTD

Ansys的[2.5D varFDTD说明](https://optics.ansys.com/hc/en-us/articles/360034917213-MODE-2-5D-varFDTD-solver-introduction)说明，该方法将竖直结构折叠成平面有效材料，主要假设不同竖直slab模式之间耦合很小；这不是完整三维矢量仿真的等价替代。

本机2023 R2.2、当前E mode (TE)设置的预检查发现：固定LN张量，只旋转0.7 µm直波导90°，两方向都得到neff≈1.765507；已有矢量FDE却分别为1.764910和1.820127。因此该具体降维设置不适合直接用于当前固定晶轴的整条弯曲光路。此结论针对本机设置，不泛化为所有版本的varFDTD都不支持各向异性。

另一次探索只拟合四个neff，虽然拟合残差很小，但Z方向场宽变成约0.678 µm，真实参考约0.366 µm。这一探索模型已排除；“neff拟合准确”不足以证明模式正确。

当前采用固定全局晶轴的**面内各向异性2D等效张量**，拟合0.7 µm波导两晶向的相位折射率和横向RMS场宽。其数字是等效材料参数，不是声称LN本征折射率发生改变。

## 独立截面校准

沿用原名义截面：400 nm LN、200 nm脊高、200 nm残余薄板、两次侧壁均与水平面70°、下方SiN移除并由SiO2填充。有限7.2 µm残余平台是既有仿真假设；当前没有画LN2/21层，因此**不能将它写成已由版图确认的真实残余平台**。

校准只拟合0.7 µm。另用真实厚度和侧壁的全矢量FDE计算1.2 µm截面作独立检查：

| 方向/模式 | neff相对偏差 | 横向强度轮廓相似度 |
|---|---:|---:|
| Y / TE0 | −0.067% | 99.88% |
| Z / TE0 | −0.070% | 99.86% |
| Y / TE1 | +0.110% | 96.23% |
| Z / TE1 | −0.292% | 93.87% |

轮廓相似度是归一化横向强度的比较，不是完整矢量复场重叠。这个模型对无源TE0比较合适，对高阶模式只有近似能力；不能用它精确验证真实TE/TM杂化。有源TE0/TE1和MUX核心仍优先保留原矢量求解数据。

## 已得到的阶段结果

- 两晶向0.7 µm直参考、0.7→1.2 µm拉锥以及两方向R80的90°欧拉弯已生成2D结果。
- R80、90°弯的Y入射案例触发能量停止（status=2）；原始目标模式功率约99.976%，已跟踪的另外3个输出模式合计约0.00332%，模式抑制比约44.8 dB。它只是等效2D孤立弯结果，不是整片真实三维插损或串扰。
- 拉锥出现约−0.0038 dB的微小负原始插损，属于需要直参考/网格检查的归一化误差，不能当作光学增益。
- 已从实际路线截取左下两条近邻接入弯，同域求解。一路入射的5 ps时间窗初筛中，目标局域TE0功率约99.929%，另一条约0.0209%，相对串扰约−36.8 dB。该例status=1，**仍是时间窗初筛，不是收敛通过**；另一条入射及时间窗检查继续进行。

近邻端口包含两条波导，其模式可能是超模或已偏局域的模；不能将mode1/mode2直接分别等同于两条波导。后处理保留复S，用端口场重构，再投影到同网格直参考的局域TE0基底，并记录基底重叠和直接传播场一致性。

上述结果暂不能用于宣布“整个链路模式没有受影响”。

总目录：`results/optical/整链路2D验证_v1/`。

- `无源各向异性拟合_v2/`：正在使用的2D等效材料及模式数据。
- `独立FDE参考_w1p2/`：两个晶向的真实截面MODE工程和场数据。
- `二维组件/`：Y直参考和首个R80、90°弯的FDTD工程。
- `基础组件批次_01/`：第一批；在R80、180°的5 ps时间窗未满足能量停止时保留检查点并结束队列。
- `基础组件批次_02_延长时间窗/`：新批次复用前四个status=2结果，延长后续时间窗；任何status=1仍明确标为初筛，允许收集后续基础组件，不能标为全部收敛。计划表含15项，其中4项复用。
- `近邻几何/`：四组接入从实际路径截取的几何及全局位置。
- `近邻联合仿真/左下_far_a_100nm/二维等效组件.fsp`：左下两条接入弯同域工程。
- `近邻联合仿真/左下_far_a_分析01/`：首个近邻初筛的局域模式投影与联合场图。
- `阶段汇总_01/`：独立截面比较图、R80传播场和已完成组件快照。

完整级联仍待：四组近邻区域的两路输入矩阵、当前GDS中MUX外部接续、模式基底和相位对齐、已有MUX/15 mm有源段接入、全光路复幅度求解。目前基础组件主要保存目标入射的一列复S，不得冒充完整多模S矩阵。

交叉器占位不计未知的真实插损、反射、模式转换和群时延；端面黑盒同样不具有完整实测模型。窗口长度、归一化和模式基底的数值核对属于名义功能验证，不是提前做制造容差。

## 可复现入口

```powershell
# 生成无源等效模型；目录必须是新目录。
.\.venv\Scripts\python.exe -X utf8 models/optical/link_2d_effective_model.py --routing-only --output-dir results/optical/自己的二维模型

# 单组件：可选reference、taper、bend90、bend180、s_bend。
.\.venv\Scripts\python.exe -X utf8 models/optical/link_2d_component.py --model results/optical/自己的二维模型/等效2D张量拟合.json --output-dir results/optical/自己的二维R80 --kind bend90 --axis Y --radius-um 80 --mesh-nm 100 --time-ps 3

# 从实际路线提取近邻两路。
.\.venv\Scripts\python.exe -X utf8 models/optical/prepare_link_2d_pair.py --routes results/layout/_历史归档/迭代版本_20260912/横向接入_v13_06_路线/左侧延时路线试算.json --pair left_lower --output results/optical/自己的近邻几何.json

# 成对波导必须一起求解；分别令source-port为far_a和far_b。
.\.venv\Scripts\python.exe -X utf8 models/optical/link_2d_component.py --model results/optical/自己的二维模型/等效2D张量拟合.json --output-dir results/optical/自己的近邻仿真 --kind near_pair --pair-config results/optical/自己的近邻几何.json --source-port far_a --mesh-nm 100 --time-ps 8

```
