## YSJ原样保留的方法

YSJ源文件的三个单元在新GDS中逐字节保留，包括原顶层、`interlayer_coupler_ln_sin`、`edge_coupler_9um_1550_sin`；只在新文件中追加四程单元和共同父单元。没有移动、缩放、旋转、展平、删层或改写YSJ图形，源文件哈希未变。

KLayout回读验证了YSJ全部13个非空图层几何异或为空。原文件已有少量端口标记向x正方向伸出边界2nm，因此合并总包围盒显示为21.800002×3.8mm，原100/30 block框仍为21.8×3.8mm。

原YSJ部分存在大于0x8000长度的GDS记录。合并为了原样保留而保留这些记录；KLayout可按无符号长度读取，仍可能显示原有警告。没有为消除警告而拆分、重写YSJ多边形；其他工具的格式兼容性需另行确认。

## 交叉器及端口连接

用户已允许增加PDK交叉器。当前共有7个`crossing_ln`，共14次光学通过，黑盒内部未添加自定义掩膜：

| 标记 | 中心坐标(µm) | 相交光路 |
|---|---|---|
| C1 | (−10530,100) | 回路3 / 输出 |
| C2 | (−10530,300) | 回路3 / 回路2 |
| C3 | (−10530,650) | 回路3 / 回路1 |
| C4 | (−10530,1050) | 回路3 / 回路1 |
| C5 | (−10530,1120) | 回路3 / 输入 |
| C6 | (−10530,1180) | 回路3 / 回路2 |
| C7 | (−8800,300) | 输入 / 回路2 |

沿同一竖直回路的C1–C6之间使用1.2µm直段连续串接，共855µm；只有这段串接总线的两端作0.7/1.2µm过渡，避免相邻器件间重复拉锥互相侵入。横向端口、C7竖直端口及两只端面耦合器均有对应100µm拉锥，总计20个0.7/1.2µm接口拉锥实例。所有窄端连接、宽端尺寸和串接直段都已作原生图形检查。

交叉器黑盒的实际损耗、串扰和群时延仍未知。增加交叉器是本轮为完成固定block内功能布线采用的取舍，不代表损耗已通过。

## 时延与速度匹配

电极截面、有源波导和晶向未因本次平移、外部布线改变，不因此重扫电极本体nRF或有源ng。重新匹配的是光学回路的长度及入口间时延；所有中心线按已有方向ng积分。

| 回路 | 总目标时延 | 无源回程时延预算 | 无源回程中心线长度 |
|---|---:|---:|---:|
| 1 | 300ps=3T | 173.6940ps | 23.5579mm |
| 2 | 350ps=3.5T | 223.7291ps | 30.3467mm |
| 3 | 300ps=3T | 173.6940ps | 23.4614mm |

这里T=100ps，对应10GHz。总目标包含前一程15mm有源传播、两次MUX本体通过、两段有源接续和两段外侧接续。两段外侧接续从200µm缩为100µm后，每回路少约1.44332ps，已在无源路线中补回。

回路1、3时延相同而几何长度略有差别，是因为竖直和水平路由比例不同，采用了各向异性方向积分。分别使用进出模式的有源拉锥ng后，实际账目为299.999769/350.000231/299.999769ps；约±0.000831°只是10GHz下的算术残差，不是材料或器件误差范围。

输入片内端口至第1程约68.6655ps，第4程入口至输出片内端口约289.1298ps，两个片内端口间合计约1307.795ps。整体传播时间不要求是RF周期整数倍。两只端面耦合器黑盒本体不在这些参考面内。

黑盒、接口拉锥及1.2µm串接段目前仍以0.7µm方向ng作占位；新100µm外接续沿用旧平均ng。它们真实复传输相位尚未提取，因此这里仍是工程预算，不宣称严格器件级相位验证，也不据此更新可观测梳齿数量。

## 本轮几何检查结果

- 一个共同顶层；原YSJ三个单元记录逐字节一致、各层几何一致。
- 两套LN1核心同层重叠面积为0，M1同层重叠面积为0。
- 新SiN挖除区与原YSJ SiN核心重叠面积为0；四程LN1与YSJ原21/2刻透区域重叠面积为0。
- 三条金属导体独立连续，六个GSG落针区正确接入各自网络。
- 两条15mm长、1.33µm宽有源脊完整；新路线没有自交，7个相交位置均为指定正交交叉器。
- 所有新增物理掩膜位于block内，端面耦合器内部不被自定义掩膜侵入。
- 本轮新增核心间距、刻蚀窗口线宽/间距、SiN挖除窗口和M1线宽/间距标记均已清除。
- 原MUX仍有40条核心线宽、40条刻蚀间距标记，未豁免，不是官方DRC全部通过。

左侧窗口仅作平面边界整理：20/1最大简化误差100nm、10/2为20nm，凹角圆滑参数1µm；不改变光学核心中心线、15mm电极或MUX本体。该窗口整理不替代实际截面的光学确认。

19项脚本单元测试通过；GDS合并后另外作了原生连接、同层重叠和源文件保留检查。这些检查不替代电磁求解。

## 复现与配套文件

```powershell
.\.venv\Scripts\python.exe models/layout/route_15mm_left_delays.py --include-io --output-dir results/layout/自己的路线新目录
.\.venv\Scripts\python.exe models/layout/build_15mm_ysj_merge.py --routes results/layout/自己的路线新目录/左侧延时路线试算.json --ysj 用户提供的YSJ文件.gds --output-dir results/layout/自己的合并新目录
```

主要入口：`models/layout/build_15mm_ysj_merge.py`；它调用原生构建脚本`klayout_build_upper_15mm.py`，并在检查通过后追加GDS单元记录。合并回读入口为`models/layout/audit_merged_block.py`，时延账目入口为`scripts/merged_layout_delay_budget.py`。

推荐目录中包含`合并清单.json`、`原生连接检查.json`、`合并回读_完整检查.json`、`合并版时延预算.json`以及整体、左侧、右侧预览图。生成文件全部留在本地；本轮没有提交Git，没有启动新光学/RF仿真，没有运行容差扫描。
