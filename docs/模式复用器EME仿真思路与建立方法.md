# 模式复用器EME仿真思路与建立方法

本文说明当前四程薄膜铌酸锂调制器中，TE₀/TE₁模式复用器为什么这样设计、模型如何建立、各类结果分别证明什么，以及如何在Ansys Lumerical MODE 2023 R2中查看模式转换过程。

本文对应当前名义工程：

- `results/optical/模式复用器_70度_EME_精细检查.lms`
- `models/optical/mode_mux_eme.py`
- `models/optical/mode_mux_cross_section_sweep.py`
- `results/optical/模式复用器_70度_EME_精细检查_S矩阵.csv`

参数扫描输出统一放在`results/optical/扫描结果/`下，不与基准工程混放，也不上传Git。

## 一、要解决的物理问题

四程调制器的有源波导需要交替使用TE₀和TE₁，而芯片输入、输出及长距离无源路由仍优先使用TE₀。因此需要一个器件完成以下选择性映射：

```text
辅助单模波导TE₀  →  双模主波导TE₁
双模主波导TE₁    →  辅助单模波导TE₀
双模主波导TE₀    →  保持在主波导中直通
```

这里不是用一个突然的波导台阶“撞”出TE₁，而是让两根波导的局部本征模沿传播方向缓慢变化，利用主波导TE₁与辅助波导TE₀之间的避免交叉实现绝热转换。

当两条未耦合模式的传播常数接近时，耦合后会形成两个超模，其有效折射率不再真正相交，而是形成间隔。若几何变化足够缓慢，输入光会沿同一条超模分支演化，最终从辅助波导TE₀变成主波导TE₁。主波导TE₀远离这次相位匹配，因此主要保持直通。

## 二、为什么先做截面本征模，再做EME

完整思路不是直接画一个三维器件就开始传播，而是分为两级。

```text
PDK截面
  ↓
单根波导FDE：确认TE₀、TE₁、群折射率和芯区局域性
  ↓
双波导局部截面扫描：寻找主TE₁与辅助TE₀的避免交叉
  ↓
构造沿传播方向连续变化的宽度和间隙
  ↓
三维EME：计算有限长度器件的模式转换、反射和串扰
  ↓
端口模式场核对 + 复S矩阵 + 传播场图
```

FDE回答“某一个截面支持哪些模式”；EME回答“光经过整段渐变结构后从哪个模式变成哪个模式”。仅有截面相位匹配不能证明有限长度器件能够高效转换。

## 三、当前截面怎样按PDK建立

### 1. 名义层叠

当前模型采用：

- X切薄膜铌酸锂；
- LN总厚度400 nm；
- LN1第一次刻蚀200 nm，形成上部脊波导；
- 保留200 nm厚的下部LN薄板；
- LN2用于局部继续刻蚀200 nm，将不需要的LN区域刻透；
- LN1和LN2侧壁均按与水平面成70°建立；
- 模式复用器下方不保留SiN，原SiN高度区域由SiO₂填充；
- 模式复用器的第一轮名义模型不加入金属电极。

侧壁角70°是当前用户指定的名义输入，不应写成代工方已保证的工艺值。400/200/200 nm的解释来自当前PDK截面理解，最终仍应与代工方工艺说明保持一致。

每一级200 nm刻蚀的单侧横向外扩为

\[
\Delta w_{\mathrm{side}}=\frac{0.2}{\tan 70^\circ}\approx 72.8\ \mathrm{nm},
\]

所以一级梯形的下边总宽比版图顶宽约大145.6 nm。脚本使用多个竖直薄层近似梯形侧壁；版图输入宽度统一解释为梯形顶宽。

### 2. 铌酸锂各向异性

当前MODE 2023 R2材料库没有可直接调用的LiNbO₃材料，因此脚本使用对象自定义各向异性介质。1550 nm名义主折射率采用Zelmon等人的同成分LN Sellmeier模型：

\[
n_o=2.211111,\qquad n_e=2.137560.
\]

EME坐标定义为：

- 仿真`x`轴：光传播方向，对应晶体Y轴；
- 仿真`y`轴：芯片横向，对应晶体Z光轴；
- 仿真`z`轴：芯片竖直方向，对应晶体X轴。

因此EME中的折射率张量设置为

\[
(n_x,n_y,n_z)=(n_o,n_e,n_o).
\]

FDE脚本的传播轴命名与EME不同，所以张量字符串的排列看起来不同；物理晶轴映射是一致的，不能只比较软件坐标中的三个数字顺序。

## 四、局部避免交叉怎样找到

脚本`mode_mux_cross_section_sweep.py`先在一系列静态双波导截面上求解本征模。扫描变量主要是：

- 主波导顶宽；
- 辅助波导顶宽；
- 两波导边缘间隙；
- 目标模式的有效折射率和场分布。

不能只看“第几号模式”。每个扫描点都要用以下信息追踪物理模式身份：

1. 场主要位于主波导还是辅助波导；
2. 主波导中的场是偶对称TE₀还是奇对称TE₁；
3. TE偏振占比；
4. 芯区能量占比；
5. 相邻扫描点之间的场重叠。

当主TE₁和辅助TE₀接近时，应看到两个超模的有效折射率互相排斥，同时场能量从一根波导逐渐转移到另一根波导。这一步用于确定三维渐变几何需要穿过的参数区域。

## 五、三维EME几何怎样建立

### 1. 几何轨迹

当前精细工程的名义参数为：

| 参数 | 数值 |
|---|---:|
| 工作波长 | 1550 nm |
| 总长度 | 750 µm |
| 靠近段 | 100 µm |
| 中央耦合段 | 550 µm |
| 分离段 | 100 µm |
| 主波导顶宽 | 1.40 µm逐渐变为1.10 µm |
| 辅助波导顶宽 | 0.30 µm逐渐变为0.40 µm |
| 两端边缘间隙 | 2.50 µm |
| 中部最小边缘间隙 | 1.00 µm |

主波导变窄、辅助波导变宽，用于推动两者传播常数穿过相位匹配点；间隙先减小再增大，用于在中部产生足够耦合，同时让输入端和输出端重新解耦。宽度和间隙都使用端点斜率平滑的函数，减少突然变化引起的反射和非期望模激发。

三段长度是EME求解器的单元分组，同时对应靠近、主要耦合和分离区域。几何本身在整段750 µm内连续变化，不是三个突变的矩形器件。

### 2. EME求解设置

当前精细工程采用：

- 三维双向EME；
- 传播方向为`x`；
- 横向计算宽度12 µm；
- 横向和竖直边界使用PML；
- 三个单元组长度为100/550/100 µm；
- 单元数为1/31/1，总计33个局部截面；
- 每个截面保留8个展开模式；
- 渐变区域使用CVCS方法降低阶梯离散误差；
- 两端端口选择软件模式1、3、4。

EME把器件沿`x`方向分成若干单元。在第`m`个单元内，场被展开为该截面的前向和后向本征模之和：

\[
\mathbf E_m=\sum_n a_{m,n}\mathbf e_{m,n}e^{-j\beta_{m,n}x}
+\sum_n b_{m,n}\mathbf e_{m,n}e^{+j\beta_{m,n}x}.
\]

求解器在相邻单元交界面匹配切向电场和磁场，得到界面散射矩阵，再把所有单元级联为整个器件的S矩阵。它既包含前向转换，也能计算反射，比只允许单向传播的近似方法更适合高折射率对比的模式复用器。

EME适合当前750 µm长的渐变器件，因为传播距离增加主要表现为模式相位积累，不需要像三维FDTD一样在整段器件内用亚波长时间域网格推进。FDTD可用于最后对缩短结构或关键局部进行独立复核，但不适合作为最初的大量长度扫描工具。

## 六、端口模式为什么不能只看编号

软件按有效折射率等规则给模式编号；当波导宽度、间隙或波长变化时，编号可能重排。因此“模式4”不是永久等同于“辅助TE₀”。

当前1550 nm精细工程经过端口场形核对后的映射为：

| S矩阵索引 | 端口1物理模式 | 端口2物理模式 |
|---:|---|---|
| 1/4 | 主波导TE₀ | 主波导TE₀ |
| 2/5 | 主波导TE₁ | 辅助波导TE₀ |
| 3/6 | 辅助波导TE₀ | 主波导TE₁ |

它们在软件端口列表中分别对应模式1、3、4。为了显示“辅助TE₀变为主TE₁”的传播过程，当前工程应选择`port 1`和`mode 4`作为输入。任何重新计算或几何修改后，都应重新查看端口模式场，而不是直接沿用这张编号表。

## 七、怎样读S矩阵

若输入为索引`i`、输出为索引`j`，目标通道功率为

\[
P_{j\leftarrow i}=|S_{ji}|^2.
\]

当前精细工程在1550 nm的名义结果为：

| 通道 | 目标通道功率 |
|---|---:|
| 主波导TE₀→主波导TE₀ | 99.6226% |
| 主波导TE₁→辅助波导TE₀ | 99.7033% |
| 辅助波导TE₀→主波导TE₁ | 99.1098% |

这说明当前理想几何下，选择性模式转换机制成立。它不等同于实际芯片插入损耗，因为当前模型没有包含侧壁粗糙散射、材料批次偏差、完整弯曲/交叉级联及实际制造误差。

判断模式复用器至少要同时检查：

- 目标通道功率；
- 回到输入端的反射；
- 进入其他端口模式的串扰；
- 未选入端口集合的辐射或高阶模功率；
- 复传输系数的相位。

多程回路的群时延不能由目标通道功率推算。应对目标复传输系数展开相位并计算

\[
\tau_g=-\frac{\mathrm d\arg S_{ji}}{\mathrm d\omega}.
\]

## 八、怎样在MODE里看到完整变化过程

### 1. 查看实际传播场

1. 运行EME，使工程进入分析模式。
2. 打开`EME Analysis Window`。
3. 选择`source port = port 1`、`source mode = mode 4`。
4. 保持`update monitors`勾选，点击`eme propagate`。
5. 返回主界面，选择覆盖整个器件的EME场监视器。
6. 打开`field profile`，选择电场并显示`Abs²`。
7. 使用XY俯视图，即横轴为传播方向`x`、纵轴为横向`y`。

预期场图应依次显示：

```text
输入端：功率位于辅助波导
   ↓
靠近区：两波导距离减小
   ↓
避免交叉附近：场形成混合超模并逐渐转移
   ↓
分离区：功率留在主波导
   ↓
输出截面：主波导内呈TE₁奇对称场形
```

不要显示`real(E)`来判断功率转移，因为载波相位会造成快速正负振荡；应显示`|E|²`或对截面功率积分。

### 2. 查看几个代表性截面

展开`EME → Cells`，依次查看`cell_1、cell_8、cell_16、cell_24、cell_32、cell_33`的`mode fields`和`neff`。这样可以看到局部超模随位置变化，但这些是EME展开基底，不完全等同于指定输入后的总传播场。

### 3. 显示几何轮廓

普通场监视器的数据不包含几何边界。若要显示波导轨迹，需要增加与场监视器同一平面的`EME Index Monitor`：

- 类型设为`2D Z-normal`；
- `x`范围覆盖0～750 µm；
- `y`范围与场监视器一致；
- `z`位置与XY场监视器完全相同。

重新运行并传播后，`index profile`显示几何，`field profile`显示光场。若要把几何轮廓叠加到同一张图，可使用MODE组件库中的`E-field outlined`分析组件，或将场和折射率数据导出后用Python/MATLAB绘制折射率等高线。

当前基础建模脚本自动建立几何、EME求解器、端口并导出S矩阵；精细`.lms`中的场监视器属于结果查看配置。若从脚本重新生成工程，应同时重新加入场监视器和折射率监视器，才能完整复现传播图。

## 九、如何从脚本复现当前精细工程

在仓库根目录使用项目虚拟环境运行：

```powershell
.\.venv\Scripts\python.exe -u models\optical\mode_mux_eme.py `
  --wavelength-nm 1550 `
  --length-um 750 `
  --approach-length-um 100 `
  --coupling-length-um 550 `
  --separation-length-um 100 `
  --main-start-um 1.40 `
  --main-stop-um 1.10 `
  --aux-start-um 0.30 `
  --aux-stop-um 0.40 `
  --end-gap-um 2.50 `
  --minimum-gap-um 1.00 `
  --cells 1,31,1 `
  --modes 8 `
  --port1-modes 1,3,4 `
  --port2-modes 1,3,4 `
  --project "results\optical\模式复用器_70度_EME_精细检查.lms" `
  --geometry-output "results\optical\模式复用器_70度_EME_精细检查_几何.csv" `
  --s-output "results\optical\模式复用器_70度_EME_精细检查_S矩阵.csv"
```

该命令会调用本机Lumerical MODE 2023 R2，重新建立几何、计算各EME单元的本征模、执行传播并导出S矩阵。运行前应避免覆盖仍需保留的工程；若只是学习或试改参数，应给`--project`、`--geometry-output`和`--s-output`指定新的文件名。

## 十、当前结果证明到哪一步

当前结果属于“1550 nm名义单器件功能通过”，证明：

- 当前PDK截面解释下存在主TE₁与辅助TE₀的避免交叉；
- 750 µm有限长度结构能够实现约99%的目标模式转换；
- 主波导TE₀可以同时保持高直通率；
- 当前端口模式和S矩阵映射已经建立。

当前结果还没有证明：

- 多个模式复用器、弯曲、交叉和四程回路级联后仍保持相同模式纯度；
- 实际制造后的插入损耗；
- 模式复用器的真实群时延已经回填到10 GHz回路长度；
- 功能完成后的工艺容差和最终流片签核。

按照当前项目顺序，应先完成名义完整光链路和传播场核对，再进入制造容差检查。
