## 本轮选择及改动

- 保持原21.8 × 3.8 mm block，不扩大边界。
- 保留15 mm T形电极、两条1.33 µm有源核心、双端GSG150 µm接口；金属图形相对冻结源几何异或为空。
- 四只MUX的750 µm耦合区各物理层以及原辅助尾端保持原形；没有采用探索中的镜像摆位或90°旋转。
- 只缩短外部接续：有源侧200→100 µm，外侧100→50 µm；保留渐变宽度，不作突然宽度跳变。缩短接续的性能不被自动视为重新场求解通过。
- 左侧回程束整体向内移动150 µm，输入竖向通道与第二回路补偿段一起重排。不是只缩短单一路径再补相交。
- 无源路由仍为0.7 µm，采用最小曲率半径80 µm、比例0.4的部分欧拉弯。
- 直路由的20/1名义总宽度6.7 µm，10/2名义总宽度16.7 µm，对应0.7 µm核心每侧外扩3和8 µm。分叉共用窗口在局部作并集、宽端封口和圆角整理；这些是绘制/刻蚀窗口，不是新增LN2材料层。
- 仍为7只PDK交叉器，没有增加数量。共14次光学通过；串接总线保持1.2 µm，只在总线两端转换宽度，避免重复拉锥互相侵入。
- 四程不新增21层；YSJ原有21/2保留。

## 周期及群时延

10 GHz对应T=100 ps。当前极性序列要求两侧回路为整数周期，中间回路为半整数周期，因此选择3T、3.5T、3T，而不是强行维持约254 ps。

| 回路 | 总间隔 | 无源回程工程时延 | 无源中心线长度 |
|---|---:|---:|---:|
| 1 | 300 ps | 175.8906 ps | 23.8570 mm |
| 2 | 350 ps | 225.9252 ps | 30.6458 mm |
| 3 | 300 ps | 175.8906 ps | 23.7606 mm |

总间隔包含前一程有源传播、出入MUX、两侧接续和无源回程。进出TE0/TE1分别使用已有模式群时延；回程按Y/Z方向ng积分。机器精度下的微小闭合残差只是预算算术结果，不代表器件具有相同精度。

交叉黑盒、0.7/1.2接口和1.2 µm串接段的真实散射群时延仍未独立提取，暂沿用已有方向ng占位；接续长度变化按旧平均ng估算。这里没有用新布线直接宣称Vπ、梳齿数或完整光电性能已验证。

## 复现

前提：本地保有PDK、冻结的v18_11源GDS、YSJ原GDS、已求出的方向ng和MUX群时延文件。保密PDK、源版图及扫描结果不随公开脚本上传。

```powershell
# 1. 先算完整五路布线和三段时延，新目录不得已存在。
.\.venv\Scripts\python.exe -X utf8 models/layout/route_cycle_matched.py --output-dir results/layout/自己的周期路线

# 2. 构建，并按原始单元记录合并YSJ。
.\.venv\Scripts\python.exe -X utf8 models/layout/build_15mm_ysj_merge.py --routes results/layout/自己的周期路线/左侧延时路线试算.json --ysj 用户提供的YSJ.gds --output-dir results/layout/自己的周期合并

# 3. 独立回读与时延账目，生成实际GDS预览。
.\.venv\Scripts\python.exe -X utf8 models/layout/finalize_cycle_layout.py --directory results/layout/自己的周期合并 --routes results/layout/自己的周期路线/左侧延时路线试算.json --ysj 用户提供的YSJ.gds

# 4. 运行不调用电磁求解器的脚本回归测试。
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s models/layout -p "test_*.py"
```
