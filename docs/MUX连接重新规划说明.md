# MUX连接重新规划

> 本文记录的v8方案因在电极外引入LN1主脊S弯，不符合“先确定直波导”的当前顺序，已被否决。最新直脊规划基线见`docs/直LN1脊连接规划说明.md`。

## 结论

v7通过横向移动`20/1`与`10/2`包络来消除端面台阶，虽然几何连续，但会让整个刻蚀窗口在电极外斜着漂移。这个方案缺少明确的光学或工艺依据，已被否决，不再作为最新工作稿。

最新v8：`results/layout/_历史归档/迭代版本_20260912/MUX重新规划平行接续_工作稿_v8_02/四程10GHz_15mm_MUX重新规划平行接续_待验证工作稿.gds`。

## 原因

最初布局只按MUX主脊端口对齐有源波导。MUX的共同包络中心位于两条脊之间，而主脊局部中心为`y=-1.95 µm`；四个MUX又采用不同镜像方向，因此左右有源端的包络中心分别落在主脊两侧。主脊接通但共同包络错位，形成端面台阶。v7继续固定MUX位置、只移动包络中心，导致用户指出的斜接。

## v8重排

1. 四个MUX共同中心分别放到上、下有源轨道`y=±30 µm`，所以有源端的`20/1`与`10/2`和电极区保持平行、同中心。
2. 15 mm有源脊和T形电极不移动。MUX的1.33→1.40 µm主脊连接段在电极外200 µm内，采用五次平滑S形中心线，从有源轨道移动到MUX本体主脊位置。
3. MUX外端主脊与辅助脊也在各自200 µm段内缓慢移动，使端点继续落在原回路坐标。三条长回路、交叉器位置和原中心线长度均不改变。
4. 有源侧至MUX本体的共同包络保持直线、固定宽度。只有外部两条波导分支逐渐分开的位置，包络才随分支单侧展开，并在端面完整匹配原两条路由的包络并集。
5. v6的0.30 µm辅助尾端保留；21层、圆弯、RF焊盘和终端均未改变。

## 核查

- 四个有源端、八个外部主/辅助端，共12个LN1接口均连接；
- 四处有源端的`20/1`、`10/2`平行连接，八个外部端的两层包络完整覆盖；
- 三种S形中心线长度均约200.01358 µm，比原200 µm增加约0.01358 µm；最小曲率半径约3.553 mm，大于PDK的80 µm下限；
- M1与LN1无平面重叠，金属2/3 µm线宽/间距检查为0项；
- 其他子单元、非相关工艺层以及v6源文件保持不变；14项本地版图单元测试通过。

整片仍有40条LN核心线宽和40条LN1刻蚀区间距标记，来自MUX本体辅助脊的0.30 µm名义曲线在法向宽度/1 nm格点检查中的标记，不是v8连接新增。三段新S形拉锥仍需验证模式传输、反射和群时延，因此v8仍是工作稿，不是流片签核版。

## 复现

KLayout加载KLink后运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 models/layout/replan_mux_connections.py `
  --output-dir results/layout/自己的MUX重新规划新目录
```

脚本固定读取v6并另存新文件，输出结构化检查结果和左右接续截图。已有v6、v7以及失败检查目录均保留，不覆盖历史数据。
