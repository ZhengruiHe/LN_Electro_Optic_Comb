# MUX尾端线宽修正

## 修改范围

v6文件：`results/layout/尾端线宽修正_工作稿_v6/四程10GHz_15mm_尾端线宽修正_待验证工作稿.gds`。

尾端是每个MUX辅助脊朝有源调制段伸出的未连接末端，不是主波导或外部路由末端。原局部坐标为x=-100至0 µm、y=1.40 µm，长度100 µm，宽度从0.15增至0.30 µm。本次改成0.30 µm等宽段，保留位置和长度；共用单元的四个实例同步更新。没有修改MUX本体、主路、电极、黑盒、弯曲和21层。

这是最小线宽修正，不是完成低反射终端设计。平头末端可能反射残余光，其影响及与主路回耦需要完整MUX含尾端仿真；不能直接沿用旧750 µm本体的转换效率作为新接续的验证证据。

## 核查

实际GDS检查确认新延伸段线宽0.30 µm、与MUX本体连续；四处尾端以外的LN1、20/1包络和其他工艺层均未改变，黑盒原内容不变，v5源文件哈希保持不变。整片LN核心线宽标记从48降至40，LN1刻蚀区间距标记从44降至40。剩余标记中心位于MUX本体局部x=0至约87.5 µm的辅助脊，需要另行判断曲线离散、法向宽度及绘制格点影响，不在本轮静默修改已仿真本体。标记数不是独立器件缺陷数。

## 复现

先打开KLayout并加载KLink，然后运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 models/layout/fix_mux_tail_layout.py `
  --output-dir results/layout/自己的尾端修正新目录
```

脚本只读取源GDS，另存新文件，在新标签中打开并定位左上尾端，保存截图和检查JSON；已有目录禁止覆盖。未启动电磁求解、未修改制造容差参数，亦未实现欧拉弯或RF焊盘。原v5其余未验证项继续有效。
